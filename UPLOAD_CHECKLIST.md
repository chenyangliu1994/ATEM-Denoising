# GitHub release checklist

Include:

- source code and configuration files
- compact CSV/JSON result files
- figure scripts
- small manifests or example files

Exclude:

- full train/validation/test `.dat` files
- `.pth` / `.pt` checkpoints
- `test_arrays_full.npz`
- large Wasserstein intermediate files
- `__pycache__`
- IDE-specific files
- GP-ReLU / Hybrid experiments not used in this study
