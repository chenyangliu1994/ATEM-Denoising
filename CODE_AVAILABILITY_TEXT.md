# Code and data availability

The source code for measured-noise partitioning, Wasserstein-based noise
augmentation, supervised data construction, two-stage FC-ED/SRCG training,
held-out testing, and figure generation is available at:

https://github.com/chenyangliu1994/ATEM-Denoising

The repository also contains the compact result files used for the reported
ablation and method-comparison experiments. Large intermediate datasets and
model checkpoints are not included.
