# Reference scripts

These are the scenario-specific scripts used for the reported E1-E4 runs.
They are kept so that the exact settings used in those runs can be checked.

For new experiments, use the generic implementation under `src/` together
with `experiments/wasserstein_ablation/`.

The reported FC-ED/SRCG runs use H512 for FC-ED, 64 hidden units in SRCG,
220 epochs in Stage 1, and 100 epochs in Stage 2.
